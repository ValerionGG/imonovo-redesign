## Regras de formato .dc.html (obrigatórias — falham em silêncio)
Esqueleto exato:
```html
<!doctype html>
<html lang="pt">
<head>
<meta charset="utf-8">
<title>Atlântico — Início</title>
<script src="./support.js"></script>
</head>
<body>
<x-dc>
<helmet>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=...&display=swap">
<style>
body{margin:0}
/* classes para hover, @keyframes, @media, :focus-visible */
</style>
</helmet>
<div style="... root fluido ...">…</div>
</x-dc>
<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":1440,"height":5200}}'>
class Component extends DCLogic {
  constructor(props){ super(props); this.state = { tab: 'moradias' }; }
  renderVals() { return { ... }; }
}
</script>
</body>
</html>
```
- Linha `<script src="./support.js"></script>` EXATA no head. Fechar todos os elementos não-void; aspas em todos os atributos.
- PAGE fluida: root sem largura px; containers `max-width` + padding lateral; grelhas `repeat(auto-fit, minmax(min(280px, 100%), 1fr))`; alturas em px/rem (nunca `%`, `vh` só se o root for ecrã inteiro — não usar); nav colapsa num telemóvel (@media em helmet). `$preview` = {"width":1440,"height": altura estimada da página}.
- `{{hole}}` = lookup com pontos APENAS (`{{item.price}}`, `{{$index}}`), nunca expressão (`{{!x}}`, `{{a+b}}`, `{{fn()}}` falham). Calcular tudo em `renderVals()`.
- Eventos: `onClick="{{ pick }}"`, `onInput="{{ setPrice }}"` com funções devolvidas por renderVals; handler por item: `items: xs.map(x => ({...x, pick: () => this.setState({sel:x.id})}))` e `onClick="{{ item.pick }}"`.
- `<sc-if value="{{ cond }}" hint-placeholder-val="{{ true }}">…</sc-if>` (sem else: usar duas flags calculadas). `<sc-for list="{{ items }}" as="item" hint-placeholder-count="3">…</sc-for>`.
- Estilos variáveis por estado: pré-calcular a string (ex. `item.tabStyle`) em renderVals e ligar `style="{{ item.tabStyle }}"`; tokens estáticos ficam inline literais.
- Classes CSS em `<helmet><style>` para hover, animações (@keyframes: reveal com clip-path/translate, ken-burns, marquee, fade), @media, grain (gradientes), `:focus-visible`. `url()` de imagens só em regras helmet, nunca em `style="…"` inline (usar `<img>` com object-fit para imagens normais).
- Sem rede exceto Google Fonts css2 `<link>` e os /_blob/ acima. Sem `<iframe>`, `<object>`, `<embed>`, sem `innerHTML`/`appendChild`, sem `window.X` próprio, sem listeners keydown globais, sem imports. JS clássico.
- Ícones: SVG inline em traço (stroke), nunca emoji. Botões icon-only com `aria-label`. Controles reais (`<button type="button">`, `<a href>`, `<input>`+`<label>`). Alvos ≥44px. Contraste texto ≥4.5:1 (cinzas de legenda escuros o suficiente; texto sobre foto com overlay).
- `data-props`: só `$preview` + 1–3 tweaks úteis (ex. cor de acento enum/color, modo denso). Texto = literal no markup (PT); dados repetidos (imóveis, serviços) em renderVals.
- Nada de Inter, Roboto, Arial, Fraunces. Nada de gradientes "AI" genéricos, cartões com borda esquerda colorida, emoji. Nada de estatísticas inventadas ("+500 clientes"): se precisar de um número use [N] placeholder ou factos reais (6 imóveis, AMI, ano de construção 2014…).
- Toggle PT/FR: state `lang`; pelo menos nav, hero e CTAs principais mudam (strings em renderVals por lang).
- Interatividade por página real e rica (é avaliada): estados hover elegantes, animações de entrada CSS, transições.
